# وب‌پی استودیو

ابزاری سبک و فارسی برای تبدیل تصویر به WebP، تنظیم کیفیت خروجی و نگه‌داری تصاویر تبدیل‌شده در یک گالری واکنش‌گرا.

## امکانات

- تبدیل تصاویر JPG، PNG، WebP، GIF، BMP، TIFF و AVIF به WebP
- تنظیم کیفیت خروجی از ۶۰ تا ۱۰۰
- کوچک‌سازی تصویر بدون بزرگ‌کردن فایل‌های کوچک‌تر
- انتخاب فایل با کلیک یا کشیدن و رهاکردن
- پیش‌نمایش، دانلود و حذف تصاویر تبدیل‌شده
- محدودیت حجم آپلود ۱۰ مگابایت و کنترل ابعاد تصویر
- رابط فارسی، راست‌چین، واکنش‌گرا و سازگار با صفحه‌کلید

## پیش‌نیازها

- PHP 8.3 یا بالاتر
- Composer
- افزونهٔ PHP Imagick و ImageMagick با پشتیبانی از WebP
- Node.js و npm

## راه‌اندازی

```bash
composer run setup
php artisan serve
```

سپس برنامه را در نشانی `http://localhost:8000` باز کنید. دستور راه‌اندازی وابستگی‌های PHP و JavaScript را نصب می‌کند، فایل محیطی محلی را می‌سازد، کلید برنامه را تنظیم می‌کند، پیوند ذخیره‌سازی را می‌سازد و فایل‌های فرانت‌اند را برای انتشار آماده می‌کند.

برای توسعهٔ فرانت‌اند با بازسازی خودکار فایل‌ها:

```bash
npm run dev
```

## آزمون و ساخت

```bash
php artisan test --compact
npm run build
```

## ذخیره‌سازی و حریم خصوصی

فایل‌های خروجی در `storage/app/public/converted` ذخیره می‌شوند و از طریق `public/storage` در دسترس هستند. فایل اصلی پس از تبدیل نگه‌داری نمی‌شود.

گالری و مسیرهای حذف در نسخهٔ فعلی بین همهٔ بازدیدکنندگان مشترک و عمومی هستند. پیش از انتشار عمومی، برای حذف تکی و پاک‌سازی گروهی احراز هویت و سطح دسترسی مناسب اضافه کنید یا برنامه را پشت یک لایهٔ دسترسی خصوصی قرار دهید.
